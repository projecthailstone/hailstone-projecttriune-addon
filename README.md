# Project Triune plugin for Hailstone

Releases of the Project Triune server's plugin for [Hailstone](https://github.com/projecthailstone), an EverQuest
RoF2 client. It adds that server's client features (LootNScoot, the server's windows, monster forms, the vault) and
stays off on every other server.

This repository holds only the releases: each one is a signed `hailstone-addon.txt` and one package for each
platform, the compiled plugin with its Lua windows. The plugin's source is not public.

## Installing

1. On Hailstone's login screen, click **Add-ons**.
2. Paste `https://github.com/projecthailstone/hailstone-projecttriune-addon` and press **Look**.
3. Check what it asks to do on the card, then press **Install**.

Hailstone keeps it up to date, and only installs updates signed with the same key as the version you installed.
